# Gotchas: Line-art Animation 주의사항 및 실패 방지 가이드

라인아트 애니메이션 제작 시 흔히 발생하는 안티패턴과 기술적 함정 목록이다. 작업을 시작하기 전에 반드시 확인한다.

---

## 1. 보행 역학(Gait) 관련 실패 사례

- **발 미끄러짐**(Foot Skating):
  • 원인: 이동 거리 계산 시 `gait.speed`와 실제 객체 이동 속도가 불일치할 때 발생한다.
  • 해결: `x += dir * walk.speed * SCALE * dt * go;` 공식을 정확히 준수한다. 지면에 닿은 지지발(stance foot)은 지면 기준 속도가 정확히 0이어야 한다.
- **타임랩스 배속 시 보행 왜곡**:
  • 원인: 하루 주기(낮/밤)가 빠르게 흘러간다고 해서 인물의 보행 속도나 위상 변화를 억지로 배속하면 경련을 일으키는 것처럼 보인다.
  • 해결: 보행 속도는 항상 인체 생리학적 속도(초당 약 2보)를 유지하고, 시간 압축은 인물의 등장 간격(스폰 주기)을 단축하여 해결한다.
- **기계적인 사인파 바운스**(Sine Wave Bob):
  - 원인: 상체나 머리를 `Math.sin(t)`로 단순 왕복 진동시키면 로봇처럼 보인다.
  - 해결: `walk.pose(phase, go)`가 반환하는 `p.bob`을 사용한다. `p.bob`은 지지발이 하중을 받을 때 내려앉고(dip), 다른 발이 스윙할 때 올라가는 역운동학적 결과를 반영한다.

## 2. 드로잉 및 조판(Drawing & Style) 관련 실패 사례

- **기계적인 직선 및 밀폐형 튜브 사지**:
  - 원인: 팔다리를 자로 잰 듯한 직선이나 닫힌 원통형 벡터로 그리면 손그림 감성이 완전히 파괴된다.
  - 해결: 반드시 `limb()`를 사용하여 끝이 닫히지 않는 두 가닥의 먹선으로 그리고, 관절은 둥글게 굴린다. `inkDefs()` 필터를 걸어 잉크가 종이에 번지는 미세한 요철(displacement)을 부여한다.
- **골격과 분리된 의복 드로잉**:
  - 원인: 옷(코트, 기모노 등)을 몸 위에 뻣뻣한 강체로 덧씌우면 다리가 옷을 뚫고 나온다.
  - 해결: 옷자락은 하체 골격 계산 결과(`p.feet[p.front].knee` 및 양 발목 좌표)를 앵커로 삼아 보폭에 따라 A자 형태로 자연스럽게 벌어지고 닫히도록 그린다. 소매와 가방은 `spring()`이나 `pendulum()` 물리로 늦게 따라오게 만든다.
- **얼굴 이목구비 과도 묘사**:
  - 원인: 작은 스케일(~95유닛)의 인물에 눈코입을 그리면 조잡해진다.
  - 해결: 얼굴은 여백으로 비워두고, 헤어스타일(상투, 쪽진 머리)이나 모자(중절모, 삿갓, 캡)로 인물의 개성을 나타낸다.

## 3. 주간·야간 팔레트(Color & Night Cycle) 함정

- **단색 면 채우기 시 클래스 누락**:
  - 원인: 바지나 가방 등 특정 부위에 단색을 칠할 때 일반 SVG `fill`을 쓰면 야간 반전 시 종이 배경 클래스(`.pp`)에 의해 먹선 반전이 오작동한다.
  - 해결: 단색 면 채우기는 반드시 `solid()` 헬퍼를 사용한다.
- **페이지 전체 배경색 오염**:
  - 원인: 장면의 낮/밤 전환을 페이지 전체 배경색과 연동하면 컴포넌트가 아니라 전체 화면 동영상처럼 느껴진다.
  - 해결: 컴포넌트는 항상 중립적인 카드 컨테이너 내부에서 완결되어야 하며, 카드 바깥의 웹 페이지 배경색은 절대 변경하지 않는다.

## 4. 렌더링 및 캡처(Verification & Headless Capture) 함정

- **헤드리스 및 백그라운드 탭의 rAF 스로틀링**:
  - 원인: 크롬 브라우저는 백그라운드 탭이나 헤드리스 환경에서 `requestAnimationFrame`을 초당 1~2프레임 수준으로 강제 스로틀링한다.
  - 해결: 검증 및 비디오 캡처 시에는 반드시 URL에 `?debug` 파라미터를 추가하여 rAF를 끄고, `window.__step(seconds)` 함수를 통해 정확히 프레임 단위(`1/fps`)로 시간을 전진시킨다.
- **Node.js TypeScript 실행 환경**:
  - Node 22.18 미만(예: Node 22.14) 환경에서 `.ts` 스크립트를 직접 실행할 때는 `node --experimental-strip-types scripts/capture.ts ...` 옵션이 필요하다.
